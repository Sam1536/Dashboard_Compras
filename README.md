# 🛍️ Dashboard de Compras | Power BI

Dashboard interativo para acompanhar a área de compras: **saving**, **custo com desconto**, **lead time** e **atraso médio de entrega**, com análise por fornecedor, por mês e por comprador.

## ✨ Recursos

- Indicadores de **Custo com Desconto**, **Lead Time de Compra** e **Atraso Médio de Entrega**
- Evolução mensal do **saving** e do custo com desconto
- Saving por fornecedor
- Lead time de despacho por fornecedor
- Filtros por ano, fornecedor e comprador
- Tooltips personalizados com custo original e custo com desconto por fornecedor

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**.
